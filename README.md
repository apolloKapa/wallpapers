# Monolith wallpapers

The wallpaper pack the [Monolith](https://github.com/apolloKapa/monolith) installer downloads.

- `images/` — pictures (go into `~/Pictures/Wallpapers`)
- live wallpapers (videos) are attached to the [`live` release](https://github.com/apolloKapa/wallpapers/releases/tag/live), since some are bigger than GitHub allows in a repository; `live/files.tsv` lists them (name, size, SHA-256). They go into `~/Pictures/Wallpapers/Live`.

These wallpapers were collected from around the web (Unsplash, moewalls, wallpaper sites and others). They belong to their creators and are **not** covered by Monolith's licence. If you made one of them and want it removed or credited, open an issue and it will be taken care of.
